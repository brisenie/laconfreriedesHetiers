# Replit setup

## Run the Expo web app

The frontend lives in `frontend`.

1. Install dependencies:

   ```bash
   cd frontend
   npm install
   ```

2. Start the web version:

   ```bash
   cd frontend
   npx expo start --web --port 5000
   ```

The Replit workflow named `Start application` runs the second command and exposes port 5000 for Preview.
